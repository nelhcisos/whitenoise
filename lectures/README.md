# Книги по лекциям (не входят в игру)

Здесь лежат три книги, пересказанные по лекциям и вебинарам. Из сборки игры они убраны, файлы сохранены целиком.

| Папка | Книга | Источник |
|---|---|---|
| `positioning/` | «Позиционирование брекетов» (учитель Сора) | вебинар М. Морозова |
| `aligners/` | «Элайнеры с нуля» | курс Пешковой (11 видео) |
| `az/` | «Элайнеры от А до Я» | вебинары 1–8 из 11 (9–11 не сделаны) |

В каждой папке: `src/` — свитки, подписи к картинкам и скрипты нарезки; `assets/` — кадры и слайды, иконка книги (у позиционирования ещё спрайты Соры).
`art/` — скрипты иконок и Соры, `tests/` — их проверки.

## Как вернуть книгу в игру

1. Перенести файлы обратно: `src/` → `src/<папка>/`, кадры → `assets/master/fig/`, иконку → `assets/books/`, спрайты `sora_*` → `assets/master/`.
2. В `src/master/master_engine.js` вернуть строку книги в `M_BOOKS`, в `index.html` — в список `BOOKS` на главном экране.
3. Скопировать `.js` книги в плоскую папку сборки вместе с `src/master/*` и `src/days/*` и запустить `python3 src/build_master.py <папка> index.html`.

Главы добавлять только в конец: прогресс игрока хранится по номеру главы.
