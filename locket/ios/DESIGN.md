# Дизайн Locket

Два источника, по ним принимается каждое решение:

1. **taste-skill v2** (`npx skills add Leonxlnx/taste-skill`), глава `references/app-screens.md` — правила для экранов, в которых работают (наш случай), тёмная тема.
2. **Vercel Web Interface Guidelines** (vercel.com/design/guidelines) — взаимодействия, состояния, формы, текст, доступность. Веб-правила переведены на iOS: «focus ring» → VoiceOver и Dynamic Type, «aria-label» → `accessibilityLabel`, «prefers-reduced-motion» → `accessibilityReduceMotion`.

Токены — в `Shared/Theme.swift`, общие компоненты — в `Locket/Components/Components.swift`. Экран собирается только из них; свои цвета, радиусы и шрифты в экранах не заводятся.

## 1. Токены

| Роль | Значение | Где |
| --- | --- | --- |
| `Palette.ground` | #000 | фон экрана |
| `Palette.surface` | #111 | карточки, поля, чипы — шаг тона над фоном |
| `Palette.raised` | #222 | вложенные поверхности, скелетоны, тост |
| `Palette.border` | #2e2e2e | линии на поверхности, рамка поля |
| `Palette.control` | #444 | обводка вторичной кнопки |
| `Palette.text` / `muted` / `faint` | #fff / #b4b4b4 / #949494 | текст: основной / вторичный / мета и плейсхолдеры (все ≥ 4.5:1 на чёрном) |
| `Palette.accent` | жёлтый Locket | **только данные** (звёзды, твои реакции, лидер недели, фото недели) и **не больше одного элемента управления на экран** (кнопка «Отправить» на камере) |
| `Palette.positive` / `negative` | #3fc07a / #e5566f | статусы и ошибки, всегда вместе с текстом или иконкой |
| `Radius.photo` / `card` / `control` | 24 / 20 / 14 | вложенные радиусы уменьшаются; чипы — капсула |
| `Space.margin` / `gap` / `cardPadding` / `section` | 20 / 16 / 20 / 40 | одно поле по бокам, один зазор по горизонтали и вертикали |
| `Space.controlHeight` / `hitTarget` | 50 / 44 | высота кнопок и полей; минимальная зона нажатия |

**Шрифт** — один гротеск (SF Pro), только системные стили, чтобы работал Dynamic Type. Не больше пяти размеров на экран: `.title` 28 (заголовок экрана, bold) · `.title3` 20 (заголовок секции, semibold; цифра-ответ экрана) · `.body` 17 · `.subheadline` 15 · `.footnote` 13. Начертаний три: regular, semibold, bold (bold — только заголовок экрана). Все числа — `.monospacedDigit()`. Скруглённый шрифт — только словесный знак «Locket».

## 2. Правила

Делаем:
- Цвет — на данных, не на интерфейсе. Глобальный `tint` белый. Выбранная вкладка выделяется яркостью, а не цветом.
- Поверхности разделяются шагом тона (#000 → #111 → #222). Не тенью и не рамкой; рамка — только у полей и вторичных кнопок.
- У каждого экрана один `ScreenTitle` — существительное, а не приветствие. Вторая строка — одна фраза о данных: находка или период.
- Самое крупное на экране отвечает на главный вопрос экрана (см. §4).
- Числа: табличные цифры; число и единица склеены неразрывным пробелом (`nbsp`): «11 очков», «3 фото», «21:00». Ноль печатается нулём, отсутствие — серым «—».
- Порядок показывается позицией или настоящим рангом «1», «2», «3» (ранг — это данные).
- Иконки — SF Symbols в контурном варианте, серые, рядом с подписью или одной кнопкой (закрыть, ещё, назад). У иконки-кнопки обязательно `accessibilityLabel`.

Не делаем (запрещено обоими источниками):
- **Эмодзи как украшение** в заголовках, подписях, кнопках, пустых состояниях, тостах: 🏆 👑 📸 ⚡️ 🥇 👋 💛 ⏰ 🗳 и т. п. Исключение — шкала оценок ✍️ 😂 🫪: её выбрали пользователи, это данные, знак вида реакции.
- Градиенты, «стекло» (`.ultraThinMaterial` и другие материалы), свечения, тени у предметов в покое.
- Капс и разрядка в подписях; маленькие подписи над заголовком.
- Плитки с иконкой или эмодзи сверху, сетки одинаковых карточек ради сетки — группа фактов становится одним списком строк.
- Модальный `alert` для ошибок загрузки — ошибка показывается внутри блока, который не загрузился (`InlineError`). Ошибки действий показываются тостом `model.show(error:)`.
- Спиннер на месте контента — вместо него скелетон реального размера (`SkeletonBlock` + `.appearsAfter()`).
- Анимации появления. Движение — только отклик на действие (нажатие, выбор, появление листа) и уважает «Уменьшение движения».

## 3. Компоненты (`Components.swift`)

| Компонент | Когда |
| --- | --- |
| `ScreenTitle(title:subtitle:)` | первая строка каждого экрана |
| `SectionHeader("…")` / `SectionHeader(title:) { trailing }` | заголовок секции, справа — текстовое действие |
| `Card { }` | группа строк на поверхности #111 |
| `LocketButtonStyle(.primary / .accent / .secondary / .destructive)` | `.primary` — белая заливка, одна на экран; `.accent` — жёлтая, только «Отправить» на камере; `.secondary` — обводка; `.destructive` — обводка, красный текст |
| `ButtonLabel(title:isLoading:)` | подпись остаётся во время запроса, спиннер слева |
| `FormField(label:error:) { TextField }` | подпись над полем, ошибка под полем; плейсхолдер — пример значения с «…» |
| `InlineError(message:retry:)` | блок не загрузился |
| `EmptyState(text:actionTitle:action:)` | пустой блок: рамка, одна фраза, следующий шаг |
| `SkeletonBlock(height:)` + `.appearsAfter()` | загрузка: серые плашки реального размера, появляются только если ждать больше 250 мс |
| `Avatar(name:size:)` | человек: инициал на приглушённом тоне его собственного цвета |
| `SquarePhoto(url:)` / `RemoteImage(url:)` | фото; загрузка — ровная серая плашка |

## 4. Экраны: вопрос, находка, порядок

**Вход и компания** (`AuthView`, `CircleSetupView`). Вопрос: «как начать?». Словесный знак Locket и одна фраза о том, что это. Поля с подписями над ними. Кнопка не блокируется заранее: при нажатии с ошибками ошибка показывается под полем, фокус переходит на первое ошибочное поле. Enter переходит к следующему полю, а на последнем отправляет форму. Во время запроса кнопка неактивна, подпись остаётся, слева спиннер.

**Камера** (`CameraScreen`). Вопрос: «что отправить?». Самое крупное — видоискатель. Сверху название компании и «Увидят: 3 друга». Жёлтая кнопка — только «Отправить». Затвор — белое кольцо. Ошибка отправки показывается под кнопками, фото не теряется. У всех круглых кнопок подписи для VoiceOver: «Вспышка», «Сменить камеру», «Выбрать из галереи», «Сделать фото», «Отменить», «Отправить друзьям».

**Лента** (`FeedView`). Вопрос: «что выложили друзья?». Находка во второй строке заголовка: «3 фото ждут твоей оценки» или «Ты оценил все фото этой недели». Фото — главный элемент. Под фото звёзды 1–3 (44 pt) и реакции ✍️ 😂 🫪. Твой выбор — жёлтым, плюс трейт `.isSelected`, плюс форма (заполненная звезда), а не только цвет. Состояния: скелетон из двух карточек; ошибка с «Повторить»; пусто — фраза и кнопка «Открыть камеру».

**Неделя** (`WeekView`, `WeekResultsView`). Вопрос: «кто ведёт и сколько осталось?». Первый блок: «Сейчас лидирует», имя лидера (`.title3` жирным, жёлтым — данные) и его очки; ниже «Итоги в воскресенье в 21:00 · через 2 дня». Дальше номинации — один `Card` со строками «Друг недели — Петя — 11 очков», «✍️ Креатив — …» (эмодзи реакции как знак вида), «⚡️» не используется. Затем «Лучшее фото», таблица (ранг цифрой, аватар, имя, серая строка с разбивкой, очки справа табличными цифрами), прошлые недели, «Как считаются очки». Пустая неделя: фраза и «Сделать фото».

**Друзья** (`FriendsView`). Вопрос: «как позвать друзей?». Код приглашения — самое крупное (моноширинный — это идентификатор). Действия «Скопировать код» (`.primary`) и «Поделиться кодом…» (`.secondary`). Ниже участники, уведомления, профиль. Последней идёт отдельная секция с выходом: кнопки `.destructive`, у каждой подтверждение с последствиями словами.

**Окно уведомления** (`NotificationContent/RatingCard`) и **виджет**: те же звёзды и реакции, тот же язык. Статус под кнопками без эмодзи: «Поставь оценку — приложение открывать не нужно», «Сохраняю…», «Оценка сохранена», ошибка с подсказкой, что делать.

## 5. Текст

- Второе лицо на «ты», действительный залог, глагол на кнопке называет действие: «Создать компанию», «Отправить», а не «Продолжить» или «ОК».
- Пункт, который открывает следующий шаг (лист, подтверждение), заканчивается многоточием: «Изменить имя…», «Удалить фото…», «Поделиться кодом…».
- Состояния процесса тоже с многоточием: «Отправляю…», «Сохраняю…». Многоточие — один символ «…».
- Кавычки «ёлочки». Числа цифрами. Число и единица — через неразрывный пробел.
- Ошибка говорит, что делать дальше: «Не удалось загрузить ленту. Проверь интернет и нажми „Повторить“».

## 6. Доступность и движение

- Зона нажатия не меньше 44×44. Иконки-кнопки подписаны. Декоративное скрыто (`accessibilityHidden`). У заголовков трейт `.isHeader`.
- Статус не передаётся только цветом: у ошибок есть иконка и текст, у выбранной реакции — трейт и рамка.
- Тосты зачитываются VoiceOver (это уже делает `AppModel.present`).
- `@Environment(\.accessibilityReduceMotion)`: при включённом — без перемещений, только смена прозрачности.
- Анимируются только прозрачность и трансформации, и только в ответ на действие человека.
