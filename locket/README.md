# Locket — фото для своих + итоги недели

iPhone-приложение для компании друзей:

- **Аккаунт** — вход по email и паролю.
- **Компания** — один создаёт, остальные вступают по 6-значному коду.
- **Камера в стиле Locket** — квадратное фото (или из галереи) + подпись, отправляется всем друзьям.
- **Пуш на экран блокировки** — с фотографией и кнопками **🔥 Огонь · 🎨 Креативно · 😂 Смешно**.
  Удерживаешь уведомление → видишь фото крупно → жмёшь кнопку → оценка ушла. Приложение не открывается, разблокировать телефон не нужно.
- **Виджет на экран «Домой»** — последнее фото друзей и те же три кнопки (iOS 17+).
- **Лента** — все фото по неделям, оценки, кто что поставил.
- **Неделя** — живая таблица очков, кто сейчас лидирует, обратный отсчёт.
- **Итоги недели** — в воскресенье в 21:00 (по Москве) сервер сам подводит итоги и шлёт всем пуш «🏆 Итоги недели»:
  - 📸 **Фото недели**
  - 👑 **Друг недели**
  - 🎨 **Самый креативный**
  - 😂 **Самый смешной**
  - ⚡️ **Самый активный**
- За 3 часа до итогов — напоминание тем, кто ещё не оценил фото друзей.

## Как считаются очки

| За что | Очки |
| --- | --- |
| 🔥 на твоём фото | 2 |
| 🎨 или 😂 на твоём фото | 1 |
| Своё фото | 2 (в зачёт до 14 фото в неделю, чтобы не спамили) |
| Каждая твоя оценка друзьям | 1 |

- 👑 **Друг недели** — больше всех очков.
- 📸 **Фото недели** — фото с самым большим счётом 🔥×2 + 🎨 + 😂 (при равенстве — где больше 🔥, потом то, что раньше выложили).
- 🎨 / 😂 — больше всех 🎨 / 😂 на своих фото.
- ⚡️ **Самый активный** — фото + оценки друзьям.
- Свои фото оценивать нельзя. Оценивать можно только фото текущей недели — после итогов голосование закрывается.

Цифры меняются в `server/src/awards.js` (`POINTS`), время итогов — переменными `WEEK_END_DAY`, `WEEK_END_HOUR`, `TZ_OFFSET_MINUTES`.

## Из чего состоит

```
locket/
├── server/   Node.js 22, без внешних зависимостей: API, SQLite, отправка пушей в Apple (APNs), итоги недели
└── ios/      SwiftUI-приложение (iOS 17+), расширение уведомлений и виджет
```

## Что нужно

1. **Mac с Xcode 16** или новее.
2. **Платный аккаунт Apple Developer** ($99 в год). Без него iOS не даёт пуш-уведомления и общий доступ к данным виджету — это ограничение Apple.
3. **Сервер** с доменом (любой VPS за ~300 ₽/мес с Docker) — или для пробы обойтись туннелем, см. ниже.
4. iPhone с iOS 17 или новее.

## Шаг 1. Ключ для пушей Apple

1. [developer.apple.com](https://developer.apple.com/account/resources/authkeys/list) → **Keys** → «+» → отметить **Apple Push Notifications service (APNs)** → скачать файл `AuthKey_XXXXXXXXXX.p8` (скачать можно только один раз).
2. Запомнить **Key ID** (10 символов, есть в имени файла) и **Team ID** (справа вверху в аккаунте разработчика).

## Шаг 2. Сервер

На сервере с Docker:

```bash
git clone <этот репозиторий> && cd whitenoise/locket/server
cp .env.example .env          # вписать домен, Key ID, Team ID, bundle id
mkdir secrets && cp ~/AuthKey_XXXXXXXXXX.p8 secrets/AuthKey.p8
docker compose up -d --build
```

Домен должен указывать на сервер (A-запись) — Caddy сам выпустит HTTPS-сертификат. Проверка: `https://ваш-домен/health` → `{"ok":true}`.
Все данные (база и фото) лежат в `server/data/` — его и бэкапить.

**Без своего сервера, чтобы попробовать:** на Mac `cd locket/server && PUBLIC_URL=https://<адрес-туннеля> npm start` и в соседнем окне `cloudflared tunnel --url http://localhost:3000` — он выдаст временный адрес `https://….trycloudflare.com`. Пуши с ним тоже работают, если задать переменные `APNS_*` (см. `.env.example`, путь к ключу — `APNS_KEY_PATH`).

Без ключа APNs сервер тоже работает, просто вместо пушей печатает их в лог.

## Шаг 3. Приложение

```bash
brew install xcodegen
cd locket/ios
```

В `project.yml` поменять три строки вверху:

- `BUNDLE_ID` — свой уникальный, например `com.masha.locket` (его же вписать в `APNS_TOPIC` на сервере);
- `DEVELOPMENT_TEAM` — Team ID;
- `API_BASE_URL` — адрес сервера, например `https://locket.example.com`.

```bash
xcodegen generate
open Locket.xcodeproj
```

Подключить iPhone, выбрать схему **Locket** и нажать ▶︎. Если Xcode ругается на подпись — открыть таргет → **Signing & Capabilities** и нажать «Try again» / выбрать команду: Xcode сам заведёт App ID, App Group и пуши.

## Шаг 4. Раздать друзьям

Удобнее всего через **TestFlight**: в Xcode **Product → Archive → Distribute App → TestFlight**, потом в [App Store Connect](https://appstoreconnect.apple.com) → TestFlight → добавить друзей по email (или включить публичную ссылку). Друзья ставят приложение TestFlight и по приглашению — Locket.
Сервер сам различает тестовые (Xcode) и боевые (TestFlight) пуш-токены.

## Как оценивать с экрана блокировки

1. Друг выложил фото → приходит уведомление «Маша 📸» с превью.
2. **Удерживаешь** его (или смахиваешь влево → «Просмотреть») — фото раскрывается крупно, снизу кнопки 🔥 / 🎨 / 😂.
3. Жмёшь — оценка отправлена, телефон остаётся заблокированным. Если связи не было, придёт уведомление «Оценка не отправилась».

Если в настройках iPhone «Показ миниатюр» стоит «Без блокировки», на заблокированном телефоне превью видно после Face ID-взгляда — это стандартное поведение iOS.

## API сервера (кратко)

Все запросы — JSON, авторизация `Authorization: Bearer <token>`.

| Метод | Путь | Что делает |
| --- | --- | --- |
| POST | `/api/auth/register`, `/api/auth/login`, `/api/auth/logout` | аккаунт |
| GET/PATCH | `/api/me` | профиль, компания, текущая неделя |
| POST | `/api/devices` | пуш-токен iPhone |
| POST | `/api/circles`, `/api/circles/join`, `/api/circles/leave` | компания |
| GET/POST | `/api/photos` | лента / загрузка фото (тело — JPEG, подпись в `?caption=`) |
| PUT/DELETE | `/api/photos/:id/reactions/:kind` | оценка `fire` / `creative` / `funny` |
| GET | `/api/week/current`, `/api/weeks` | живая таблица и прошлые итоги |

Тесты сервера: `cd server && npm test` (полная неделя: регистрация → фото → оценки → напоминание → итоги).
