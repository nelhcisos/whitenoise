# Locket — фото для своих + итоги недели

iPhone-приложение для компании друзей:

- **Аккаунт** — вход по email и паролю.
- **Компания** — один создаёт, остальные вступают по 6-значному коду.
- **Камера в стиле Locket** — квадратное фото (или из галереи) + подпись, уходит всем друзьям.
- **Пуш на экран блокировки** с фотографией. Удерживаешь уведомление → фото крупно, под ним **⭐ от 1 до 3** и реакции **✍️ креатив · 😂 смешно · 🫪 жесть**. Нажал — оценка ушла, приложение не открывается, телефон не разблокируется.
- **Виджет на экран «Домой»** — последнее фото друзей с теми же кнопками.
- **Лента** — все фото по неделям, кто что поставил.
- **Неделя** — живая таблица очков, кто сейчас лидирует, обратный отсчёт.
- **Итоги недели** — в воскресенье в 21:00 по Москве сервер сам подводит итоги и шлёт всем пуш «🏆 Итоги недели»:
  📸 **фото недели**, 👑 **друг недели**, ✍️ **самый креативный**, 😂 **самый смешной**, 🫪 **самый безбашенный**, ⚡️ **самый активный**.
- За 3 часа до итогов — напоминание тем, кто ещё не оценил фото друзей.

> 🫪 — новый эмодзи, его рисует только iOS 26.4 и новее. На более старых iPhone вместо него будет пустой квадратик.

## Как считаются очки

| За что | Очки |
| --- | --- |
| Каждая ⭐ на твоём фото | 1 |
| Каждая ✍️, 😂 или 🫪 на твоём фото | 1 |
| Своё фото | 2 (в зачёт до 14 фото в неделю, чтобы не спамили) |
| Каждая твоя оценка или реакция друзьям | 1 |

- 👑 **Друг недели** — больше всех очков.
- 📸 **Фото недели** — больше всех звёзд в сумме (при равенстве — где больше реакций, потом то, что раньше выложили).
- ✍️ / 😂 / 🫪 — больше всех таких реакций на своих фото.
- ⚡️ **Самый активный** — фото + оценки друзьям.
- Свои фото оценивать нельзя. Оценивать можно только фото текущей недели.

Цифры — в `server/src/awards.js`, время итогов — в настройках сервера (`WEEK_END_DAY`, `WEEK_END_HOUR`, `TZ_OFFSET_MINUTES`).

# Запуск без Mac — всё через браузер

Приложение собирает и отправляет в TestFlight GitHub (на своём Mac в облаке, бесплатно для открытых репозиториев). Сервер ставится одной командой на арендованный VPS.

## Что понадобится

1. **Apple Developer Program** — $99 в год ([developer.apple.com/programs](https://developer.apple.com/programs/)). Без него Apple не даёт ни пуши, ни TestFlight, обойти это нельзя. Mac для оформления не нужен. Оплата — банковской картой; карты российских банков Apple сейчас не принимает.
2. **VPS** с Ubuntu 24.04 — самый дешёвый тариф (1 ядро, 1 ГБ памяти, публичный IP), обычно 200–400 ₽ в месяц у любого хостинга. Свой домен не нужен.
3. iPhone с iOS 17 или новее у каждого друга.

## Шаг 1. Два ключа Apple

Нужны **два разных** ключа: один для пушей (его получит сервер), второй для сборки (его получит GitHub).

**1а. Ключ для пушей (APNs)**
1. [developer.apple.com/account/resources/authkeys](https://developer.apple.com/account/resources/authkeys/list) → «+».
2. Имя любое (например, «Locket push»), отметь **Apple Push Notifications service (APNs)**, окружение — **Sandbox & Production**.
3. Скачай файл `AuthKey_XXXXXXXXXX.p8` — скачать его можно только один раз, сохрани.
4. Запиши **Key ID** (10 символов) и **Team ID** — он виден в [Membership details](https://developer.apple.com/account#MembershipDetailsCard).

**1б. Ключ App Store Connect (для сборки)**
1. [appstoreconnect.apple.com/access/integrations/api](https://appstoreconnect.apple.com/access/integrations/api) → **Team Keys** → «+».
2. Имя «Locket CI», доступ **Admin** (нужен, чтобы сборка сама выпускала сертификаты).
3. Скачай `AuthKey_YYYYYYYYYY.p8` (тоже один раз), запиши **Key ID** и **Issuer ID** (он вверху страницы).

**1в. Придумай Bundle ID** — уникальное имя приложения в обратной записи, например `com.masha.locket` (только латиница, цифры, точки).

## Шаг 2. Сервер

Открой консоль своего VPS (у хостинга обычно есть кнопка «Консоль» в браузере) и вставь:

```bash
curl -fsSL https://raw.githubusercontent.com/nelhcisos/whitenoise/claude/locket-friends-app/locket/server/install.sh | sudo bash
```

Скрипт поставит Docker и спросит:
- **домен** — просто Enter, будет бесплатный адрес вида `203-0-113-7.sslip.io` с HTTPS;
- **Key ID**, **Team ID** и **Bundle ID** из шага 1а и 1в;
- **содержимое файла** `AuthKey_XXXXXXXXXX.p8` из шага 1а — открой его в блокноте, скопируй всё и вставь.

В конце он напишет адрес сервера, например `https://203-0-113-7.sslip.io` — он понадобится дальше.
Обновить сервер — та же команда ещё раз. Данные (база и фото) лежат в `/opt/locket/locket/server/data`.

## Шаг 3. Секреты в GitHub

[github.com/nelhcisos/whitenoise/settings/secrets/actions](https://github.com/nelhcisos/whitenoise/settings/secrets/actions) → **New repository secret**, шесть штук:

| Имя секрета | Что вписать |
| --- | --- |
| `LOCKET_TEAM_ID` | Team ID (шаг 1а) |
| `LOCKET_BUNDLE_ID` | Bundle ID (шаг 1в) |
| `LOCKET_API_URL` | адрес сервера из шага 2, с `https://` |
| `ASC_KEY_ID` | Key ID ключа App Store Connect (шаг 1б) |
| `ASC_ISSUER_ID` | Issuer ID (шаг 1б) |
| `ASC_KEY_P8` | всё содержимое файла `AuthKey_YYYYYYYYYY.p8` из шага 1б |

Секреты никто, кроме сборки, не видит — даже в открытом репозитории.

## Шаг 4. Сборка

1. [Actions → «Locket → TestFlight»](https://github.com/nelhcisos/whitenoise/actions/workflows/locket-testflight.yml) → **Run workflow** → ветка `claude/locket-friends-app` → **Run workflow**.
2. **Первый запуск остановится с ошибкой «В App Store Connect ещё нет приложения…» — так и задумано**: он зарегистрировал Bundle ID, и теперь можно завести приложение:
   [appstoreconnect.apple.com/apps](https://appstoreconnect.apple.com/apps) → «+» → **Новое приложение**: платформа iOS, имя — любое свободное (просто «Locket» занято настоящим Locket, возьми например «Locket нашей банды»; на телефоне всё равно будет написано Locket), язык — русский, Bundle ID — выбери свой, SKU — `locket`.
3. Запусти workflow ещё раз. Минут через 15 он загрузит сборку, ещё через 10–30 минут она появится в App Store Connect → TestFlight.

Сборка каждый раз выпускает временный сертификат Apple и после загрузки отзывает его — хранить ничего не нужно, на уже загруженные сборки это не влияет.

## Шаг 5. Позвать друзей (TestFlight)

App Store Connect → твоё приложение → **TestFlight**:
1. **Внешнее тестирование** → «+» → группа «Друзья» → добавь сборку.
2. Заполни «Информацию о тесте» (почта для отзывов, пара слов о приложении) и отправь на проверку. Первая проверка Apple обычно занимает до суток, следующие сборки — быстрее.
3. Включи **публичную ссылку** и отправь её друзьям. Они ставят приложение **TestFlight** из App Store, открывают ссылку — и устанавливают Locket.

Быстрее, без проверки Apple: **Внутреннее тестирование** — но тогда каждого друга нужно добавить пользователем в App Store Connect (Пользователи и доступ).

## Шаг 6. Начали

1. Каждый регистрируется по email, разрешает уведомления.
2. Один создаёт компанию во вкладке «Друзья» → кнопка «Позвать друзей» отправляет код. Остальные вступают по коду.
3. Добавь виджет: долгое нажатие на экран «Домой» → «+» → Locket.

## Как оценивать с экрана блокировки

1. Друг выложил фото → приходит «Маша 📸» с превью.
2. **Удерживай** уведомление (или смахни влево → «Просмотреть»). Откроется фото, под ним ⭐ ⭐ ⭐ и ✍️ 😂 🫪.
3. Нажимай — оценка уходит сразу, внизу появится «Отправлено ✓». Можно поставить и звёзды, и несколько реакций. Нажать на ту же звезду ещё раз — убрать оценку.

Если в настройках iPhone «Показ миниатюр» стоит «Без блокировки», на заблокированном телефоне фото откроется после взгляда Face ID — это стандартное поведение iOS.

## Если что-то пошло не так

- **Сборка красная** — открой её в Actions, нажми на красный шаг и скопируй текст ошибки (мне или тому, кто поможет).
- **Сервер** — журнал: `cd /opt/locket/locket/server && sudo docker compose logs --tail 50`. Изменить ответы на вопросы установщика: запусти его с `LOCKET_RECONFIGURE=1` (`… | sudo LOCKET_RECONFIGURE=1 bash`).
- **Пуши не приходят** — проверь, что в шаге 2 вписан ключ APNs (1а), а Bundle ID совпадает с секретом `LOCKET_BUNDLE_ID`.

## Для разработчиков

```
locket/
├── server/        Node.js 22 без зависимостей: API, SQLite, пуши в APNs по HTTP/2, итоги недели
│   └── install.sh установка на VPS (Docker + Caddy, HTTPS через sslip.io)
└── ios/           SwiftUI (iOS 17+), проект описан в project.yml (XcodeGen)
    ├── Locket/                 приложение
    ├── NotificationService/    скачивает фото в уведомление
    ├── NotificationContent/    окно «фото + ⭐ + ✍️😂🫪» по долгому нажатию
    ├── LocketWidget/           виджет с кнопками (App Intents)
    ├── Shared/                 общий код (токен в keychain-группе, запросы оценок)
    └── ci/asc.mjs              подпись для TestFlight через App Store Connect API
```

Тесты: `cd server && npm test` (полная неделя: регистрация → фото → оценки → напоминание → итоги) и `node --test ios/ci/*.test.mjs` (подпись против поддельного API). CI (`.github/workflows/locket.yml`) гоняет их и собирает приложение для симулятора.

С Mac можно собирать и локально: `brew install xcodegen && cd ios && xcodegen generate`, в `project.yml` поменять `BUNDLE_ID`, `DEVELOPMENT_TEAM`, `API_BASE_URL`.

### API

Все запросы — JSON, авторизация `Authorization: Bearer <token>`.

| Метод | Путь | Что делает |
| --- | --- | --- |
| POST | `/api/auth/register`, `/api/auth/login`, `/api/auth/logout` | аккаунт |
| GET/PATCH | `/api/me` | профиль, компания, текущая неделя |
| POST | `/api/devices` | пуш-токен iPhone |
| POST | `/api/circles`, `/api/circles/join`, `/api/circles/leave` | компания |
| GET/POST | `/api/photos` | лента / загрузка фото (тело — JPEG, подпись в `?caption=`) |
| PUT/DELETE | `/api/photos/:id/stars` | звёзды `{"stars": 1–3}` / убрать |
| PUT/DELETE | `/api/photos/:id/reactions/:kind` | `creative` ✍️ / `funny` 😂 / `wild` 🫪 |
| GET | `/api/widget` | последнее фото друга для виджета |
| GET | `/api/week/current`, `/api/weeks` | живая таблица и прошлые итоги |
